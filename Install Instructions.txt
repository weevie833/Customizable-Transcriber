INSTALLING CUSTOMIZABLE TRANSCRIBER

The app runs on your own computer. Your images, profiles and transcripts stay
there; only the images you choose to transcribe are sent to the AI provider
(Google Gemini or Anthropic Claude) whose API key you enter.

You need:
  - Windows 10 (2018 or later) or Windows 11, or
    a Mac with Apple silicon (M1 or later) and macOS 11 or later
  - An internet connection
  - A Gemini or Claude API key (the app's Getting Started page explains how
    to get one)

Nothing is installed system-wide and no administrator rights are needed.
Jump to the section for your computer: WINDOWS or MAC.

On a Mac, the easiest way is the disk image described in the MAC section. If
you use the ZIP instead, the app's folder has two start files. Double-click only
the one for your computer:
  Start Customizable Transcriber (Windows)   - on a Windows PC
  Start Customizable Transcriber (Mac)       - on a Mac


==============================================================================
WINDOWS
==============================================================================

INSTALL

1. Right-click the app's ZIP file and choose Extract All, then click Extract.

2. Open the extracted folder until you see "Start Customizable Transcriber (Windows)".

3. Double-click "Start Customizable Transcriber (Windows)".
   If Windows says it protected your PC, click More info, then Run anyway.

4. Wait a few minutes while it sets itself up. Your web browser opens when it
   is ready. Leave the black window open. Closing it stops the app.

5. Click Getting Started in the app for a walkthrough of your first
   transcription.


USING THE APP LATER

Double-click "Customizable Transcriber" on your desktop. Setup puts this
shortcut there for you. Your browser opens to the app, at
http://127.0.0.1:8765. Close the black window when you are finished.

To start the app from the taskbar instead, right-click the shortcut and choose
Pin to taskbar. On Windows 11, choose Show more options first. Then one click
starts the app.

If the shortcut isn't on your desktop, double-click "Start Customizable
Transcriber (Windows)" in the app's folder.


UPDATING

Download the new ZIP, extract it, and replace the old folder with the new one
(or put it anywhere you like). Double-click "Start Customizable Transcriber (Windows)"
in the new folder once; the desktop shortcut then points to it. Your profiles,
transcripts and settings are kept, because they are stored outside the app's
folder.

If the new version uses a newer Python (for example, a security update), that
first start downloads it and sets the app up again, which takes a few minutes.
Close any other Customizable Transcriber window first.


WHERE YOUR PROFILES ARE

Every prompt profile you create or edit is saved as one .json file in:
  %APPDATA%\Customizable Transcriber\profiles
which is normally
  C:\Users\<your name>\AppData\Roaming\Customizable Transcriber\profiles

AppData is a hidden folder. To open it, click the address bar in File Explorer
(or press Windows+R), paste the first line above, and press Enter.

The example profile that comes with the app is in the "profiles" folder inside
the app's folder. If you change it, your changed copy is saved in the folder
above. To give a profile to someone else, use Import/Export Profiles on the
Prompt Builder page instead of copying files.


REMOVING THE APP

Delete the desktop shortcut and the extracted folder. Then delete these two
folders. The first holds the app's private copy of Python; the second holds
your profiles, transcripts and settings, so keep it if you may want them back:
  %LOCALAPPDATA%\Customizable Transcriber
  %APPDATA%\Customizable Transcriber


==============================================================================
MAC
==============================================================================

INSTALL (recommended)

1. Download the Mac disk image:
   https://github.com/weevie833/Customizable-Transcriber/releases/latest/download/Customizable-Transcriber-Mac.dmg

2. Double-click "Customizable-Transcriber-Mac.dmg" in your Downloads folder.
   In the window that opens, drag "Customizable Transcriber" onto the
   Applications folder. Then eject the disk image (the eject button next to
   it in Finder's sidebar).

3. Open "Customizable Transcriber" from your Applications folder. macOS asks
   once whether to open an app downloaded from the internet: click Open.
   The app is signed and checked by Apple, so there is no other warning.

4. A Terminal window opens. The first time, wait a few minutes while it sets
   itself up. Your web browser opens when it is ready. Leave the Terminal
   window open. Closing it stops the app.

5. Click Getting Started in the app for a walkthrough of your first
   transcription.


OR INSTALL WITH ONE LINE IN TERMINAL

1. Open Terminal: in Finder, choose Applications, then Utilities, then
   Terminal (or press Command-Space, type Terminal, and press Return).

2. Copy this whole line, paste it into Terminal, and press Return:

   curl -fsSL https://raw.githubusercontent.com/weevie833/Customizable-Transcriber/main/install-mac.sh | bash

3. Wait a few minutes while it downloads and sets itself up. Your web browser
   opens when it is ready. Leave the Terminal window open. Closing it stops
   the app.

4. Click Getting Started in the app for a walkthrough of your first
   transcription.

This way, too, macOS doesn't show its "Apple could not verify" warning, and
there is no folder to keep track of. Both ways put the app's files in
  ~/Library/Application Support/Customizable Transcriber/App
so you can switch between them.


OR INSTALL FROM THE ZIP

1. Double-click the app's ZIP file in your Downloads folder. A folder appears
   next to it. Move that folder wherever you want to keep the app, for
   example your Documents folder.

2. Open the folder and double-click "Start Customizable Transcriber (Mac)".


3. The first time, macOS says it can't verify the file. Click Done (not Move
   to Trash). Then open System Settings, choose Privacy & Security, scroll
   down to the message about "Start Customizable Transcriber (Mac)", and click Open
   Anyway. Enter your Mac password if asked, then click Open Anyway again.
   (On macOS 14 or earlier you can instead Control-click the file, choose
   Open, then click Open.) macOS asks only once.

4. A Terminal window opens. Wait a few minutes while it sets itself up. Your
   web browser opens when it is ready. Leave the Terminal window open.
   Closing it stops the app.

5. Click Getting Started in the app for a walkthrough of your first
   transcription.


USING THE APP LATER

Start "Customizable Transcriber" from your Applications folder (if you used
the one-line install or the ZIP, setup adds it to the Applications folder in
your home folder), from Spotlight (Command-Space, type
"Customizable"), or from Launchpad. To start it with one click, drag it to
the Dock. Your browser opens to the app, at http://127.0.0.1:8765. Close the
Terminal window when you are finished (click Terminate if asked).

If that app is missing, install from the disk image or paste the install line
into Terminal again (or, if you
installed from the ZIP, double-click "Start Customizable Transcriber (Mac)" in
the app's folder).


UPDATING

The app tells you when a new version is available. Close the app's Terminal
window, then download the disk image again (step 1 above) and drag the app
into Applications, choosing Replace. Open it as before.

Or close the app's Terminal window and paste the install line into Terminal
again. It installs the latest version, or just starts the app if you already
have it. If you installed from the ZIP before, this moves you to the one-line
install; you can then delete the old folder.

If you install from the ZIP instead: download the new ZIP, open it, and
replace the old folder with the new one.
Double-click "Start Customizable Transcriber (Mac)" in the new folder once (macOS
asks to confirm it again, as in step 3); the app in Applications then points
to it. Your profiles, transcripts and settings are kept, because they are
stored outside the app's folder.

If the new version uses a newer Python (for example, a security update), that
first start downloads it and sets the app up again, which takes a few minutes.


WHERE YOUR PROFILES ARE

Every prompt profile you create or edit is saved as one .json file in:
  ~/Library/Application Support/Customizable Transcriber/profiles

The Library folder is hidden. To open it, in Finder choose Go > Go to Folder,
paste the line above, and press Return.

The example profile that comes with the app is in the "profiles" folder inside
the app's folder. If you change it, your changed copy is saved in the folder
above. To give a profile to someone else, use Import/Export Profiles on the
Prompt Builder page instead of copying files.


REMOVING THE APP

Delete "Customizable Transcriber" from your Applications folder (or from the
Applications folder in your home folder, if you used the one-line install or
the ZIP), and the app's folder, if you installed from the ZIP. Then, in Finder,
choose Go > Go to Folder, enter
  ~/Library/Application Support/Customizable Transcriber
and delete the folders named App (the app's files, if you used the disk image
or the one-line install) and Runtime (the app's private copy of Python). The rest of that folder holds your profiles, transcripts and settings; delete it
too only if you won't want them back.


==============================================================================
BOTH
==============================================================================

A browser bookmark to http://127.0.0.1:8765 opens the app only while the app's
window (black window on Windows, Terminal on a Mac) is open. A bookmark can't
start the app.

If that window shows a message, send its text to whoever gave you the app.

On an Intel Mac, or if you prefer a terminal, follow the manual setup in
README.md.
